PCA9685 PWM

To calibrate: use Servo (µs) mode, move a servo to its safe limits, and press Set min / Set max under "Calibrate", then enter the angle range between them (e.g. 180). Angle mode then uses degrees: 0° = min, range = max.

Workflows

Channels in this workflow:
1) Pick the channels this workflow controls. 2) Move the servos where you want them and press "Add step" to record the selected channels as a waypoint; repeat for each point (e.g. start → middle → end). 3) Fine-tune any angle (degrees) directly in the step. A selected channel that is switched off is recorded at mid-range. Channels you don't select are never touched.
